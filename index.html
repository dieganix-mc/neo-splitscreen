INDEPENDENT PROJECT

About Neo.

Neo no longer invokes or depends on Nucleus Co-op.

✧

What works

Native Windows enumeration of keyboard and mouse HID entries, detection of visible Java windows, and two-window layout.

⌁

What is next

Physical-device identification, per-window routing, focus-independent Minecraft input, camera movement, and full gameplay validation.

ⓘ

The earlier v0.1.0 installer uses Nucleus Co-op and does not represent this independent development version. No installer for this version should be treated as gameplay-ready.
