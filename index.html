MINECRAFT 26.2 SESSION

Session workspace.

Install the Fabric input runtime in each Minecraft game directory, then inspect devices and arrange two windows.

01

Install Minecraft input runtime

Select each Minecraft 26.2 Fabric game directory. Neo copies the 26.2 mod into its mods folder. In each game, press Alt + F8 to select that player's keyboard and mouse. This runtime is a GPL-licensed port of Mouse-mouse.

02

Connected input devices

Windows can expose multiple HID entries for one physical keyboard. Select devices inside each Minecraft instance.

INDEPENDENT PROJECT

About Neo.

Neo no longer invokes or depends on Nucleus Co-op.

✧

What works

Native device detection, two-window layout, and a Minecraft 26.2 Fabric input mod that starts with its Raw Input splitter.

⌁

What is next

Validate separate keyboards and mice across two Minecraft instances, unfocused gameplay, and independent camera movement.

The earlier v0.1.0 installer uses Nucleus Co-op and does not represent this independent development version. No installer for this version should be treated as gameplay-ready.
