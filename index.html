How input works
Neo uses Nucleus Co-op's Minecraft handler and Proto Input to identify each keyboard and mouse, maintain input for both windows, and arrange the game view. Assign devices inside Nucleus when it opens.

FOUR SIMPLE STEPS

Build your session.

Follow these steps in order for two keyboards and two mice.

01

Install the input engine

Download the official Nucleus Co-op release, extract it, and select its NucleusCoop.exe. Neo does not install or modify the game.

No executable selected
02

Add Minecraft Java Edition

Open Nucleus Co-op and install its Minecraft Java Edition handler. Follow the handler's launcher and profile prompts. Use separate game accounts when required.

03

Pair each device

Move each mouse and press a key on each keyboard to identify them. Assign one mouse and one keyboard to each player slot in Nucleus. Select a left/right or top/bottom layout.

Launch and play

Start the session in Nucleus. Open a world to LAN in one instance and join it from the other. Press End to lock or unlock input after both instances are ready.

About Neo.

A focused setup companion for Minecraft Java split-screen.

✧

Why another app?

Neo gives Minecraft players a focused, animated path into the existing Nucleus Co-op and Proto Input workflow. The routing and game hooks come from those independent open-source projects.

⌁

What you need

Windows 10 or 11, two keyboards, two mice, Minecraft Java Edition, enough memory for two game instances, and the official Nucleus Co-op release.

ⓘ

Game versions, launchers, mods, devices, and PC performance vary. Neo cannot guarantee compatibility with every setup. Test both cameras, movement, clicks, scroll wheels, inventory, and focus before a longer session.
